# 原生悬浮任务栏与界面风格

默认采用经典纸页和 Windows 系统任务栏布局。配色、明暗模式、开合样式和界面风格分别保存。

## 界面风格

在设置的外观页选择经典纸页、柔雾纸页或通透玻璃。柔雾纸页降低纸纹并增加通透感；通透玻璃移除纸纹，使用系统模糊和半透明底色。内容区保留文字对比度。不支持窗口合成或启用高对比度时使用清晰的不透明背景。

## 任务栏设置

从 0.21.2 起，在「设置 → 任务栏外观设置 → 任务栏形态」选择「原生悬浮胶囊」。Explorer 现有任务栏左右缩进、底部留白，并形成圆角。开始按钮、应用图标、托盘和时钟继续由 Windows 原生任务栏提供。可以配合系统默认、纯色、模糊和亚克力材质。

点击「预览」试用 12 秒，再点「应用」保存。选择「系统布局」恢复全宽。退出折页时还原尺寸和轮廓，主程序异常结束时由恢复进程还原。任务栏工作区与自动隐藏行为继续由 Windows 管理。

本机实测覆盖 Windows 11 26H2 26340.10013 的单屏水平任务栏，验证窗口身份、左右和底部留白、圆角、取消和异常恢复。其他版本与混合 DPI 多屏需要另外验证。

## 数据和开发

界面风格保存在 `preferences.json`。新增的 `FloatingLayout` 字段保存在 `TaskbarAppearance/settings.json`，同一配置继续保存材质和场景。两版独立悬浮栏的数据留在 `FloatingTaskbar` 供历史版本使用。

折页通过 Win32 调整 Explorer 所属的原生绘制窗口。UI 验收使用 QA 构建的 `--taskbar-appearance-self-test`。实机验收使用 `--sandbox 独立目录 --native-taskbar-shape-self-test`，会短暂调整当前 Explorer 任务栏并还原。
