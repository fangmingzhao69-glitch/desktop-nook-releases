# 原生悬浮任务栏与界面风格

默认采用经典纸页和 Windows 系统任务栏布局。配色、明暗模式、开合样式和界面风格分别保存。

## 界面风格

在设置的外观页选择经典纸页、柔雾纸页或通透玻璃。柔雾纸页降低纸纹并增加通透感；通透玻璃移除纸纹，使用系统模糊和半透明底色。内容区保留文字对比度。不支持窗口合成或启用高对比度时使用清晰的不透明背景。

## 任务栏设置

在「设置 → 任务栏外观设置 → 任务栏形态」选择「胶囊形态」。Explorer 现有任务栏把开始按钮、应用图标、托盘和时钟收在同一个居中的圆角胶囊内。胶囊宽度随显示的控件增减，原生图标行在可见轮廓内垂直居中。应用区和托盘之间使用较深的双像素分隔线。分隔线左侧预留一个原生按钮位，便于打开任务栏右键菜单。

「样式」提供液态玻璃和柔雾玻璃。液态玻璃在任务栏背景上叠加折射边缘和渐变高光，柔雾玻璃使用均匀的背景模糊。两种样式都使用现有的 Windows 背景采样，染色和不透明度可以调整。

使用 Windows 居中排列或胶囊形态时，折页主面板对准折页图标中心。胶囊模式依据图标位置和所属应用识别悬停预览、工具提示及临时弹窗，使用 Windows CalculatePopupWindowPosition 在当前显示器工作区内定位。托盘中的标准菜单和工具提示也可按图标原始位置匹配。「显示隐藏的图标」面板跟随托盘箭头。日期和通知沿用系统定位。

部分腾讯电脑管家版本把信息球画成与任务栏分开的窗口。Windows 允许普通权限移动时，折页将它放入胶囊内，位于分隔线右侧、托盘箭头左侧。如果电脑管家以更高权限运行，可以勾选「自动连接信息球」并首次确认 Windows 授权；以后启动折页或再次启用胶囊会自动连接，无需重复授权。「临时定位信息球…」仍可用于单次连接。

自动连接只为当前 Windows 账户登记一个按需任务，无登录或定时触发器，不保存密码。任务固定运行 Program Files 受保护目录中的独立定位助手，任务及组件由 Administrators 拥有，普通权限只有读取和执行权限。主程序不会被以管理员身份启动，任务不接受可变命令或脚本。关闭自动连接时移除任务；退出胶囊或关闭折页时，助手还原信息球并结束。移动安装目录或定位组件需要更新时，需重新确认该组件的授权。隔离模式禁止安装或运行该特权任务。

点击「预览」试用 12 秒，再点「应用」保存。选择「系统布局」恢复全宽。退出折页时还原尺寸和轮廓，主程序异常结束时由恢复进程还原。任务栏工作区与自动隐藏行为继续由 Windows 管理。

本机实测覆盖 Windows 11 26H2 26340.10013 的单屏水平任务栏，验证原生控件收拢、居中、打开和关闭应用时伸缩、取消和异常恢复。其他版本与混合 DPI 多屏需要另外验证。

## 数据和开发

界面风格保存在 `preferences.json`。`FloatingLayout` 字段保存在 `TaskbarAppearance/settings.json`，同一配置继续保存材质和场景。0.21.4 移除「细线与窗口规则」设置区，材质组件改用场景的细线和 Peek 默认值，旧的逐窗口配置继续可读，但不再参与外观切换。

折页通过 Win32 调整 Explorer 所属的原生绘制窗口。胶囊启用时，Explorer 内的任务栏组件会在处理窗口定位前保留胶囊位置，同时让原生控件继续按可用宽度排列。升级后如果旧的任务栏组件仍载入，先在任务管理器重启一次「Windows 资源管理器」。UI 验收使用 QA 构建的 `--taskbar-appearance-self-test`。实机验收使用 `--sandbox 独立目录 --native-taskbar-shape-self-test`，会短暂调整当前 Explorer 任务栏并还原。
# 0.21.17 原生预览与动画坐标

胶囊仍使用 Explorer 原生任务栏与图标。预览卡片所在的全屏 XAML 宿主在整个胶囊会话内保留定位校正，隐藏卡片或切换图标时不恢复到屏幕原点。主程序发布实际按钮矩形；原生窗口位置处理和 XAML 布局更新直接读取当前鼠标所在的按钮，保持卡片、裁剪与命中位置一致。退出胶囊或恢复系统样式时撤销校正。

最小化与还原沿用系统动画，通过 Explorer 任务栏及桌面线程的 `WH_CALLWNDPROCRET` 观察系统 `SHELLHOOK / HSHELL_GETMINRECT` 请求，在原生处理后修正目标矩形。兼容普通矩形和新版 Windows 的两点紧凑格式，并保持原始返回格式；按 AppUserModelID 对应到实际按钮，识别不到时使用受边界约束的任务栏位移。只在胶囊启用时调整，不修改其他应用进程或固定项顺序。

分隔线仍为两个物理像素，颜色调整为 ARGB `9B647080`，左侧保留一个原生图标位供右键操作。配色改变后通知 Windows 重新读取折页的任务栏分组图标，普通启动不重写固定快捷方式或 Taskband 顺序。

本机 Windows 26340.10032 的 38 项实机检查通过；Chrome、微信连续切换 18 次、234 个采样未出现预览宿主退回屏幕原点，静止预览截图已核对图标对齐。证据见 `验证结果/*0.21.17.json`。这不代表已覆盖所有 Windows 版本、多显示器布局或全部第三方软件。

0.21.18 补齐开始菜单入口的主题图标与重启属性。实机发现，窗口和固定快捷方式均为青柠图标时，开始菜单入口仍可让任务栏显示紫色；同步该入口并发出精确图标通知后，实际任务栏图标变为青柠。正常启动仅校正属于本程序的开始菜单入口，正确时不重写文件；固定项仍只在升级或主动切换主题时更新。新增回归覆盖重复启动时主题保留、图标元数据、启动参数及无关入口保护。
