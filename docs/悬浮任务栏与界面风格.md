# 悬浮任务栏与界面风格

折页新增三种界面风格和两种任务栏模式。默认保持经典纸页与 Windows 系统任务栏。配色、明暗模式、开合样式和界面风格分别保存。

## 界面风格

在设置的外观页选择经典纸页、柔雾纸页或通透玻璃。柔雾纸页降低纸纹并增加通透感；通透玻璃移除纸纹，使用系统模糊和半透明底色。内容区保留文字对比度。不支持窗口合成或启用高对比度时使用清晰的不透明背景。

主面板的通透玻璃是系统模糊材质；悬浮任务栏的液态玻璃另由原生 GPU 着色器实现实时背景折射。两种材质实现不同。

## 任务栏设置

在设置的任务栏外观设置页选择 Windows 系统任务栏或悬浮任务栏（替换 Windows 任务栏）。系统模式继续提供原有外观、场景和窗口规则。悬浮模式提供液态玻璃、柔雾玻璃、纯色，以及高度、图标大小、底边距离、宽度、放大、透明度、模糊、折射、高光、染色、状态入口和多屏设置。

点击「试用 12 秒」切换实际任务栏，再点击「保留设置」保存。超时、撤销或离开设置页会恢复已保存模式。试用后修改参数，可以重新试用。

悬浮固定项可拖动排序，也可以在折页收纳图标的右键菜单中选择固定到悬浮任务栏。悬浮排序与折页分类排序分开保存。应用切换、窗口预览、开始菜单、系统托盘、控制中心和日历由原生核心提供。聊天内容读取和独立桌面小组件不启用。

从 0.21.1 开始，悬浮模式会隐藏 Windows 任务栏并释放它占用的屏幕边缘。折页确认原栏已隐藏后才确认切换成功。切回系统模式、预览超时或退出程序时恢复系统任务栏。原生守护和恢复记录负责异常退出后的恢复。0.21.0 已保存的悬浮模式沿用现有材质和布局，下次启动时按替换模式运行。

## 数据和开发

`preferences.json` 新增可选 VisualStyle，缺失时为 paper。原子保存和更新快照均保留该字段。

`FloatingTaskbar/settings.json` 及 `.bak` 保存折页的模式和参数。`Engine` 内保存原生核心配置、固定列表、开始菜单布局、缓存、恢复状态及日志。`Components` 是按组件内容摘要隔离的可重建原生文件。完整备份仍复制整个 Data。

主程序是任务栏模式的控制方，原系统外观组件与悬浮组件互斥运行。原生组件没有主收纳存储写权限和接口。普通启动不改写用户在 Windows 任务栏固定的快捷方式或排列。

开发构建自动运行 `native/scripts/Build-Dock.ps1`。原生回归使用 `Build-Dock.ps1 -Tests`；集成检查使用 QA 构建的 `--sandbox 独立目录 --floating-taskbar-self-test`，覆盖风格组合、模式与材质、计时回退、真实启停及父进程异常退出。

沙箱不会隐藏真实系统任务栏，也不会接管系统托盘。因此该检查不代表已在本机验证真实任务栏隐藏和恢复的全部组合；混合 DPI 多屏、HDR、显卡切换与其他任务栏软件共存仍需额外实机验证。
