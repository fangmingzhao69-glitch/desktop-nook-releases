# 标签与分栏调整（0.16.1）

日期：2026-11-17。

右侧标题改为“标签”，原“新建项目、项目管理”等界面文案统一改为分类用语。“记一条”直接创建包含一个空条目的待办清单，不再显示文字类型菜单。Notes 数据格式、稳定 ID 与目录保持兼容，0.16.0 的文字记录不删除、不强制转换，仍可查看、编辑、导出和恢复。

统计改为“2 条记录 · 待完成 4 · 已完成 1”，不换行。搜索匹配数追加到同一行；超出时省略，悬停可查看完整统计，不缩小字号。

## 分栏问题与修正

旧分隔线由 GridSplitter 修改列宽，但图标列数直到 DragCompleted 才更新。拖动时左侧保持原列数，会先挤压图标；布局刷新仍按已保存的旧比例调整列宽，可能与拖动争用。动画快照与分类入场效果也未在拖动开始时统一清理。

改为专用 Thumb 的拖动处理，由同一条路径计算列宽及边界。拖动期间暂停旧比例重算和异步任务栏重新定位，同时取消两侧入场/百叶效果，释放旧快照。每次移动更新两侧宽度与图标列数，不重建标签编辑器。松手保存新比例，Esc 或取消恢复拖动前比例；下次展开根据新布局重新捕获。布局未变化时继续复用动画快照。

新增真实鼠标回归：捕获分隔线、连续移动、逐帧检查两侧可见、图标在拖动中换列、刷新右侧不回跳、松手不跳位、保存后重读一致、重新展开动画正常及 Esc 恢复。

仍需更多混合 DPI 多屏和长时间使用验收。所有回归在独立沙箱运行，不改任务栏固定入口或真实收纳内容。发布结果记录在 docs/验证结果 中。
