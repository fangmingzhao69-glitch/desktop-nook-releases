# 图标台球

在主窗口顶栏点击「图标台球」。选择当前分类、全部收纳图标或桌面图标镜像，选择中八、斯诺克、九球追分或十五球追分，设置辅助线和图标样式，然后点击「开始台球」。各球组分别为 15、21、9、15 个目标球，另有白球；下次沿用所选来源、球组和辅助线偏好。

游戏默认占所在屏幕约 40% 面积并居中。球形图标使用规则配色的圆球。原始图标保留图案比例和轮廓，编号显示在旁边；不同规则使用对应开局摆法。移动鼠标瞄准，在台面内按住左键蓄力，松开击球。力度条越满，击球越强；球全部停稳后可再次击球。释放到台面外会取消本次蓄力。辅助线显示首次碰撞或碰库的大致方向。

将图标打入六个球袋。白球入袋不算得分，会尝试在安全位置放回；无安全位置时，点击台面空处摆球。最后一个图标入袋后显示本局时间、杆数和每个图标平均用时。

- 空格或上方按钮：暂停 / 继续。
- 切换到其他窗口、最小化或更改窗口大小：自动暂停，回到游戏后点击继续。
- 重新开始：确认结束当前局，再重新摆球；未完成局不计成绩。
- Esc / 退出游戏 / 关闭窗口：结束本次游戏，随手继续常驻。
- 游戏仍在运行时，从原入口选择「继续图标台球」可唤醒原对局，也可「退出台球」。

来源图标不足时会复制补足，只影响球阵；桌面和收纳内容保持原状。游戏不执行文件、不改变桌面排列，也不会把球的坐标写成收纳顺序。

设置中可选择单人练习、本地双人对战、创建好友房间或加入好友房间。[好友联机使用与验收](好友联机使用与验收.md)开局先阅读规则并点击开始，左右收球槽收集已入袋目标；双人左侧玩家 1、右侧玩家 2，双方分数和回合显示在顶部。工具栏可关闭音效，击球、球体碰撞与落袋使用实际台球录音。碰撞声随力度变强，入袋声还随入袋角度而变化。双人采用规则卡中列出的简化本地规则。设置和成绩保存在当前数据目录的 `Games/IconBilliards/settings.json`、`scores.json`，后者保留最近 100 局与各球组的历史最佳。游戏底部不显示许可和窗口尺寸提示；开源许可位于「设置 → 关于与更新 → 图标台球许可」。游戏画面及取图在临时进程中，退出后结束；游戏期间另有一份运行开销，不能把主进程一项当作总内存。
