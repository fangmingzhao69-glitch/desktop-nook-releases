# 项目便签实现与验收

日期：2026-11-17。当前正式版本：0.16.0。已补完正式打包、隔离升级及发布。旧 0.15.1 客户端真实在线检测、下载和校验通过；本机安装未主动覆盖，可通过软件内更新获取。

## 已实现

沿用轻匣 WPF 视觉，将软件收纳与项目便签放在同一个窗口。默认 1120×627.2 逻辑像素，左侧六列图标，右侧项目横向标签、新建项目、记一条、项目内搜索与卡片。分隔线可拖动，比例自动保存。窄窗减少左侧列数，保持原字号与图标比例；自由窗口最小宽度改为 800，仍受屏幕工作区限制。

项目支持创建、重命名、排序、归档、删除与恢复。归档项目只读，从项目管理进入；恢复后继续编辑。删除时可转移现有记录到其他项目，或将项目及记录一起移入回收站；恢复项目只恢复同批删除的记录，不复活此前单独删除的内容。项目名按稳定 ID 关联，重名不合并。

记录支持可直接编辑的标题与多行文字、待办清单、勾选统计、常用、跨项目移动、导出、回收站恢复与二次确认永久删除。回车新增待办，空项退格删除，输入法组字期间不执行此类结构变更。切换项目恢复搜索、滚动、当前编辑卡片及选区。左侧切分类不重建右侧编辑控件。

## 保存与升级

便签使用独立 `Data/Notes/notes.json` 与 `.bak`。与设计初稿建议的逐条文件不同，实现采用一个有修订号的项目/记录快照，使跨项目移动、整项目删除和恢复在一次发布中完成，不需要多个文件间的事务补偿。便签状态不写入 `state.json`、`item-order.json` 或收纳分类。

编辑保留在内存草稿；停输 500 ms 保存，连续输入最长约 2 秒提交一次，组字期间延后。保存串行执行，临时文件刷盘后同目录替换，旧修订拒绝覆盖。自动保存不重建正文控件，也不改变正在编辑的卡片顺序。界面偏好保存不更改正文修改时间。

保存失败保留草稿，状态栏提供重试、导出。切项目、收起、启动软件、关闭、退出、迁移和更新前提交草稿；失败中止相关操作。更新暂存期间禁用编辑，备份整个 Notes 目录；数据迁移沿用完整目录复制，卸载保留 Data。系统正常结束会话时尝试保存，失败可取消结束；强制终止、断电仍可能丢失最后未落盘输入。

主文件损坏时读取验证通过的备份，并复制保留损坏原文件。两份均不可读时阻止写入，避免覆盖空数据。数据量增加后每次保存需要序列化完整快照，尚未对超大便签库作性能承诺。

最小化闲置后释放可重建卡片控件，保留数据草稿；恢复窗口时重建。沿用整窗百叶动画及截图预算，不新增常驻进程。AUMID、固定入口及已有任务栏顺序未改写。

## 隔离试用

从仓库根目录运行：

```powershell
pwsh -NoProfile -File native/scripts/Preview-Notes.ps1
```

首次试用是空项目。默认试用数据保存在 `%TEMP%/Qingxia-Notes-Preview`，可重复打开继续试用；这是临时目录，不用于存放唯一的重要记录。可用 `-Sandbox` 指定新的独立测试目录。脚本不读取或替换安装版数据。

专项验证入口：`--sandbox 独立目录 --notes-self-test`。只允许沙箱，生成 `notes-verification.json` 及真实 WPF 界面截图。普通运行不执行测试或创建演示项目。

## 验证边界

核心检查覆盖收纳旧功能及便签事务、重名、归属验证、修订冲突、损坏恢复、文件被占用与重试。便签界面覆盖多行中文文本自动保存、控件不重建、项目隔离、编辑选区恢复、待办回车/勾选、搜索、新建可见、保存失败与重试、默认六列、窄窗可读性、整体收起、闲置恢复、归档只读及更新备份字节校验。

真实中文输入法候选窗/连续组字、混合 DPI 多屏与显示器移除、强制断电、极大数据量和长时间常驻性能仍需额外实机覆盖；程序注入中文文本不能替代中文输入法验收。已发布并完成隔离安装器升级测试；真实本机安装尚未覆盖，可由用户通过软件内更新执行。

具体检查数量与报告见同目录 `验证结果/项目便签验收-2026-11-17.json`。实机截图为 `images/项目便签实机预览.png`，其中项目与应用均为演示数据。
