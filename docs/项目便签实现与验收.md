# 项目便签实现与验收

适用于 **随手 0.19.2**。用户操作见[使用说明](使用说明.md)。

## 存储

便签使用独立的 `Data/Notes/notes.json` 和 `notes.json.bak`。格式 2 按分类组织 `Categories[]`，每个分类保存 `Project` 和 `Records`，文件同时记录修订、活动分类和分栏比例。分类和便签使用稳定 ID，便签记录通过 `ProjectId` 归属分类。读取旧格式 1 时自动迁移，旧回收站记录归入归档。

便签、细项和分类的删除直接移除数据。用户主动归档的内容可按原分类查看和恢复。未完成清单排在已完成清单之前，分类和便签顺序随数据保存。文字记录和待办均可保存局部删除线。多行粘贴逐行保留纯文本，Markdown 导出使用 `.md` 文件。

## 保存与恢复

编辑先进入内存草稿，通过修订校验后原子替换主文件。保存失败时保留草稿。主文件损坏时读取有效备份并留存损坏原件。两份文件均无法读取时暂停写入。整体迁移或更新备份应包含完整 `Notes/` 目录。

## 隔离验证

从仓库根目录运行 `pwsh -NoProfile -File native/scripts/Preview-Notes.ps1` 可隔离试用。使用开发验收包的 `--sandbox 独立目录 --notes-self-test` 可生成 `notes-verification.json`。正式发布的便签测试通过 88 项。[0.19.2 验收报告](验证结果/随手设置与台球-0.19.2.json)
