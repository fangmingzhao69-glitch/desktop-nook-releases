# 轻匣 0.17.0-preview.1 任务栏外观预览

本轮按[整合方案](任务栏外观整合方案.md)交付可单独试用的第一阶段候选。在「更多 → 任务栏外观」选择系统默认、透明或纯色，设置颜色和透明模式的不透明度。首次默认关闭。支持应用、12 秒预览和取消恢复。旧版 TranslucentTB 设置可从文件中只读导入，原文件保留。

在构建 26340 上，使用「导入 26340 兼容组件」选择随附的 `TranslucentTB-2026.2-26340-preview.zip`。轻匣匹配固定 SHA-256 后存入专用目录，首次启动前复核组件文件。检测到同会话的独立版时，需要用户先从其系统托盘退出，轻匣才会接管。其他 Windows 11 构建使用固定版本的上游官方便携包。真实外观测试请在独立 Windows 桌面完成。沙箱仅验证设置和组件导入。

## 组件来源与构建

官方 TranslucentTB 基线为 `2026.2/d4636e439865df0a1a1419db408e055740ce5c74`。独立 clone 中只应用历史本机补丁中有关任务栏结构的两份源码变更。以 MSVC 14.51、固定版本 NuGet 依赖和 Detours 源码构建 x64 `ExplorerTAP.dll`，原版与重建版的导出名一致。将其替换进已核验的官方 x64 便携 ZIP，其余组件文件保持官方版本。对应源码、补丁、依赖版本与构建步骤和预览包一起留存。[官方基线与发行](https://github.com/TranslucentTB/TranslucentTB/releases/tag/2026.2) · [上游兼容性讨论](https://github.com/TranslucentTB/TranslucentTB/pull/1371)

兼容 ZIP SHA-256 为 `1c91b81d1296842f4af22d79a9e6ebe9fa084dce2374c5cc1db7c180207cc624`。兼容 DLL SHA-256 为 `4f321fa9fbca30ac3de335201d5a161daab45005ab8ec86a253a4f3afed72904`。便携运行依赖 x64 Microsoft VCLibs 14.0.33519 及以上和 Microsoft UI Xaml 2.8 8.2501.31001 及以上。当前机器只读查询显示对应依赖已经具备。

## 验收范围

- 沙箱从「更多」实际打开设置界面。验证默认关闭、保存和重读、预览取消、失败时回到默认、独立版设置只读导入、官方包与修复包的核验、拒绝篡改和更新备份。
- 实际样式、Explorer 重建、登录、自启、异常退出后的恢复及多屏验收，需要匹配当前 26H2 的虚拟机或独立 Windows 测试桌面。当前机器没有可用的隔离 Windows 桌面，既有 TranslucentTB 正在使用。正式版放行待这些检查通过。
- 预览安装包使用专用安装路径、测试登记和数据根。安装后从包内的预览快捷方式进入沙箱。系统任务栏实测在隔离 Windows 会话中单独运行候选 EXE，并使用干净的数据根。

验证入口为 `--sandbox 独立目录 --taskbar-appearance-self-test 官方ZIP 26340兼容ZIP`。该入口验证组件包内容和界面，不启动 TranslucentTB。正式发行按维护规则保留源码、安装包和在线更新校验。
