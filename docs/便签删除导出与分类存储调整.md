# 便签删除、导出与分类存储调整（0.16.2）

2026-11-18。右侧显示名恢复为“便签”。单条、分类、全部导出统一为 UTF-8 Markdown（`.md`），包含分类标题、清单名称、正文及标准 `- [ ]` / `- [x]` 待办状态。

待办明细编辑框的右键菜单使用主窗口 Popup 和应用蓝青 ContextMenu / MenuItem 主题，提供剪切、复制、粘贴、删除此项。删除直接移除细项并提交快照；最后一项也可删除，再通过“添加待办”补充。清单卡片右键或省略号菜单提供重命名、常用、移动、归档、导出和删除。名称可直接点击标题编辑并自动保存，也可通过右键重命名。

分类删除可先迁移全部记录，也可确认后连同记录直接删除；清单删除确认后移除全部明细。便签不再有回收站或已删除内容恢复入口。删除不会设置归档标记。归档分类保留只读查看、恢复为活动分类；归档清单从分类管理菜单按分类列出，可取消归档、导出和删除。

## 分类存储格式

继续使用安装目录 `Data/Notes/notes.json` 和 `.bak`，保证现有整目录备份、迁移及更新暂存逻辑兼容。格式升至 2：顶层保存 Format、Revision、ActiveProject、LeftFraction、Categories；每个 Categories 元素包含 Project（分类元信息和编辑位置）及 Records（本分类全部清单/正文）。分类和清单 ID 保持稳定，移动后记录跟随目标分类存储。空的旧删除字段不写入格式 2。

分类、排序、正文、完成状态和编辑位置在同一原子快照中提交，避免跨分类移动时出现半写入。`.bak` 是上一份有效快照的故障恢复备份，不是产品内的回收站。删除不会清除独立历史备份或损坏文件留存。

读取格式 1 时在内存迁移，下一次保存写格式 2。旧文字记录及待办保持类型、名称、内容和完成状态；旧回收站分类/记录转为归档并清除删除标记，避免版本升级静默丢失内容。旧程序不支持格式 2，升级后如需回退必须使用升级前整目录备份，不能让旧版覆盖新版数据。
