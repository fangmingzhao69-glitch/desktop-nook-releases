# 好友邀请联机实施方案

2026-11-13。用户已要求先形成方案再实现，并选择本轮先做本机双端验收。当前正式版 0.14.1；本方案完成后才进入新版本发布。

## 范围与流程

保留单人和同机双人，新增「创建好友房间」「加入好友房间」。房主选球组并创建，复制邀请信息给朋友；朋友粘贴加入。局域网列表可自动发现房间，未持有邀请凭证的局域网加入需房主确认。双方阅读规则并准备后开始，固定房主为玩家 1、朋友为玩家 2。

不建立账号、排行榜、公网匹配服务或云中继，不自动配置路由器、UPnP 或关闭防火墙。公网 IPv6 与局域网 IPv4 / IPv6 直连，组网工具提供的可达地址也可使用；仅有 IPv6 配置不等于入站已放通。界面提供连接状态与失败说明，邀请码为包含地址的复制串，不假装无目录服务也能解析六位短房号。

## 模块与通信

- 新增纯 .NET 网络模块，引用现有 Games.Core；客户端继续单 EXE / 共享 .NET 10，无额外安装网络 SDK。
- 只在游戏进程创建或加入房间时启动网络资源，普通收纳常驻不监听端口。退出、维护和更新关闭房间及连接。
- TCP 默认 38471，端口冲突时可选择可用端口并写入邀请；双栈监听支持 IPv6 / IPv4。局域网发现用 UDP 38472，广播 IPv4，亦可向指定地址探测；IPv6-only 网络通过邀请加入。
- TLS 自签证书在本局生成，邀请携带 SHA-256 指纹并固定校验；另用随机 256 位邀请凭证验证加入。无需加入系统信任证书。Windows Schannel 不支持直接使用临时 ECDSA 密钥，因此实现采用不含 PersistKeySet 的用户级临时密钥容器，在证书正常释放时清理；不创建应用 PFX 文件，邀请凭证只留在内存。已核验测试前后无新增密钥容器遗留，未读取密钥内容。
- 邀请包含协议 / 规则版本、房间 ID、球组、过期时间、地址候选及证书指纹。只接受明确 IP 地址和合法端口，限制大小，不执行其中命令或文件路径。
- UDP 发现只返回房间 ID、球组、端口及证书指纹，绝不广播邀请密钥。无密钥加入需要房主在游戏中确认，并限制等待与并发。

## 一致性与操作

房主网络层持有独立的纯核心对局，固定 1/240 秒推进物理，在运动中约每秒 20 次发布状态；闲置不空转模拟。两端窗口只显示房主状态，不各算一份结果。客户端以相邻快照插值绘制约 60 FPS；每杆结束发完整状态，球位、入袋顺序、复位、分数、组别、目标、轮次及胜负全部以房主为准。

只传瞄准方向、力度、自由球位置、准备与对局操作，不传软件路径、文件名、真实文件或桌面排列。两端球号和颜色一致，软件图案各用本机快照。声音事件由房主带序号广播，各端用已有实录本地播放，去重防止重连重响。

每条操作带会话、轮次、客户端请求序号；房主验证席位、当前回合、状态、有限数值与范围，拒绝越权、重复 / 过期击球、NaN / 超界摆球、协议不兼容和超大消息。网络帧采用有界长度前缀，单连接串行写入，慢连接限额并断开，不能堆积无限快照。

联机失焦、缩放、最小化只影响本机输入和绘制，不暂停对方比赛；规则窗局部遮挡并禁操作。全局暂停 / 重开经双方同意；退出确认后结束连接，首版不迁移房主。联网局独立标记，不影响单人最佳。

## 断线重连

加入后发独立的座位恢复凭证，保留在游戏进程内。朋友掉线后房主保留对局并暂停推进，预留 60 秒自动重连；恢复使用恢复凭证，不允许只拿旧邀请的人抢座位。重连恢复完整最新状态和操作序号；不重放已接受的击球。超时结束本局并显示原因，不把中断记录作正常胜负。房主退出或进程消失，本局结束；不声称支持房主迁移或主机重启恢复。

## 验收

1. 纯网络 / 核心：邀请过期和畸形、错误指纹 / 凭证、双栈回环、占座、准备、错方击球、去重、摆球、比分 / 快照一致、发现不泄密、加入确认、断线恢复 / 超时、取消与端口释放。
2. 本机双端：两个独立游戏进程，各自图案和设置，真实 TCP + TLS 创建 / 加入、准备、连续轮换、快照一致、断线重连、关闭和成绩隔离；仅使用合成桌面及 --sandbox。
3. 原玩法回归及旧版升级，前后核对真实主索引、排序、偏好与文件库摘要。网络故障不能改收纳主数据。
4. 记录联机运行开销、包体积、闲置 / 最小化和退出资源，不强制 GC 或裁剪工作集。

本轮验收明确止于本机双端和回环网络。真实两台电脑、不同网络、公网 IPv6 入站及各种防火墙组合未测试时保留为待验收项。无需为了测试擅自改变 Windows 或路由器安全设置。

## 交付顺序

方案 → 快照 / 邀请 / 通信核心 → 房主与重连 → 局域网发现与界面 → 双端及回归 → 提交推送 → 正式构建 / 草稿哈希核验 / 发布 → 同盘备份升级与数据核对。实施结果和实际完成范围在文末补录，不把设计目标写成已测事实。

## 实施结果

18 项网络核心和 18 项本机双端检查通过，实际设置 / 加入窗、两个独立游戏进程、回环 TLS、固定房主计算、重连及双端成绩已落地；原有 47 项本地游戏及 53 / 37 核心回归保持。用户选定范围中的真实跨电脑与公网仍待验收，完整证据和使用步骤见[使用与验收](好友联机使用与验收.md)。正常退出后新增 Windows 临时密钥容器为 0。没有自动改动防火墙、路由器或真实收纳内容来做测试。

0.15.0 已按项目发布流程公开并应用本机；数据和原玩法核对通过。方案目标中的本机双端验收已完成，真实两台电脑 / 公网部分按用户选择保留待验收，详见使用与验收文档。
