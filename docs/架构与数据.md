## 数据保存

默认数据根目录 `%LOCALAPPDATA%\DesktopNook` 包含：

- `state.json` / `state.json.bak`：分类与收纳索引及备份。
- `migration.json`：进行中的操作日志，用于中断恢复。
- `vault/<id>/`：逐项恢复清单、快捷方式副本或同卷托管内容。
- `updates/`：下载、更新计划、元数据快照及更新结果。
- `instance.pid`：当前实例定位信息。

普通文件和文件夹优先同卷原子移动；与数据目录不同卷时，内容保存在原桌面同卷的隐藏 `.DesktopNookVault` 中，恢复信息仍位于数据目录。只备份 JSON 或默认数据目录不能覆盖所有跨卷实际内容。

收纳普通文件后的编辑会随移回保留。同名目标不覆盖；目录联接、符号链接及未落地的云占位内容不按普通实目录处理。

快捷方式通过内容校验和逐项清单保留恢复依据。操作中断时，根据日志、托管内容及源/目标实际状态恢复。恢复副本及更新备份均保存在本机，不构成云备份。

## 偏好与系统入口

窗口尺寸和关闭偏好位于 `HKCU\Software\DesktopNook\Settings`；自启使用当前用户的 Windows Run 项。窗口比例只调整窗口，内容维持默认尺度并自动计算列数。

回收站收纳保存并调整当前用户 Explorer 的桌面图标可见性设置，移回时还原，不移动回收站内容。

## 在线更新

客户端查询 `fangmingzhao69-glitch/desktop-nook-releases` 的最新正式版，仅接受该仓库的 `DesktopNook-win-x64.exe`，无需发布凭据。

下载核对来源、大小、SHA-256、产品名和版本。确认后交给独立助手，等待当前程序正常退出，备份旧程序并替换，再启动新版并等待就绪确认。

更新不迁移收纳内容，会保存元数据快照。替换失败时尝试还原；新版未确认就绪时保留备份和更新记录。

## 验证范围

覆盖故障恢复、同名保护、附加流、文件/目录往返、快捷方式启动、原生 OLE、窗口大小、图标像素和更新。原生检查需要可交互 Windows 桌面。

混合 DPI 多屏的完整组合仍待实机覆盖。Shell 扩展、公共桌面权限和图标原资源质量受具体系统及应用影响。
