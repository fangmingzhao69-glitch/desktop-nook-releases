# 文档截图

截图来自 Windows 上实际运行的桌面小筑 0.9.1，使用独立 `--sandbox` 配置和自行创建的演示快捷方式。没有采集日常桌面、个人分类或实际用户文件。

| 文件 | 内容 |
| --- | --- |
| overview.png | 所有分类下的演示收纳区 |
| collect.png | 选择待收纳项目和目标分类 |
| category.png | 选中“办公”分类后的筛选结果 |
| more-menu.png | 更多菜单、当前版本与更新入口 |
| size-menu.png | 固定比例、自由调整和锁定宽高比入口 |
| size-80.png | 80% 窗口，图标大小保持默认 |
| size-150.png | 150% 窗口，图标大小保持默认 |
| update.png | 检查更新结果和当前版本 |

演示模式会禁用开机自启等影响真实系统的设置，因此个别菜单项呈灰色。更新截图时应继续使用隔离示例数据，检查图片中不含个人路径或个人内容。
