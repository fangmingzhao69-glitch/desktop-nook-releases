# 项目交接：折页

当前正式版为 **0.20.1**。折页 / ZHEYE 是 Windows 桌面收纳工具，左页管理软件、文件和文件夹，右页记录便签和待办。葡萄气泡、西瓜冰棍、青柠电波、蓝莓苏打四套配色与浅色、深色和跟随系统模式独立选择。

0.20.1 加入 Windows 托盘入口，可唤醒已收起的面板，也可进入设置或退出。旧固定快捷方式的文件名仍可能出现在任务栏的悬停提示中。

0.20.0 采用折角图标和双页布局。新数据默认按 61:39 分栏，原有分栏偏好按已保存值加载。任务栏外观为设置窗口内嵌页，分组显示开关、场景、色块和滑块。

安装、在线升级或使用「设置 → 常规 → 创建或刷新程序入口」时更新属于本程序的开始菜单和固定入口图标，保留实际固定位置、目标、参数及工作目录。普通启动保留用户固定入口，已有快捷方式的文件名也会保留。

## 兼容标识与数据

- 保留 `DesktopNook` EXE、程序集、数据和注册表标识、`DesktopNook.DesktopNook` AUMID、现有 GitHub 资产名以及安装器内部产品名和卸载文件名。
- 整体备份包含当前 Data，尤其是收纳和排序文件、偏好、`vault/`、`Notes/` 和游戏数据。仍由旧清单引用的跨卷托管文件也需要备份。[安装目录数据存储](安装目录数据存储.md)
- 开发、安装验证与恢复测试使用独立沙箱。真实维护恢复按用户明确要求执行，操作前检查最新现场状态并保留恢复资料。
- 任务栏外观引擎随主进程启停，首次启用时下载并校验组件。图标台球按需启动同一 EXE 的游戏子进程，成绩由主程序保存。
- 维护图标使用 `native/DesktopNook.App/Assets/AppIconDrawing.xaml` 和小尺寸变体。当前界面资源和主题见[界面与交互规范](界面与交互规范.md)。

历次版本说明和历史资料索引见[清理记录](清理记录.md)。
