## 5. 数据保护与恢复边界

默认数据根目录含 `state.json`、`.bak`、`preferences.json`、`.bak`、`category-policy.json`、`migration.json`、`vault/`、`updates/`、`instance.pid` 等。

- 普通文件/文件夹可能托管在原桌面同卷的隐藏 `.DesktopNookVault`。只备份 JSON 或默认数据目录不能覆盖所有真实内容。
- 索引格式 2 允许删除「未分类」，但必须至少有一个分类；不要再自动补回默认分类。
- 文件和文件夹在收纳期间可继续编辑，移回时必须保留最新内容；同名冲突不能覆盖已有目标。
- `preferences.json` 优先保存窗口与关闭偏好；不要将取消勾选的 false 当作缺省值重置。
- 该设备配置目录带 EFS 保护。不要解除用户文件/目录加密，也不要把唯一恢复内容当作测试产物清除。
- 同盘现场备份仍保留在 `%LOCALAPPDATA%\DesktopNook.BrandBackup-*` 等目录，本次项目清理没有触碰它们。
- `--maintenance=restore`、`--collection-inventory ... --apply` 会修改真实内容，禁止作为常规检查调用。不要在日常数据上执行「全部移回桌面」来验证功能。
- 开发与回归使用新建 `--sandbox` 目录。运行普通程序默认会访问真实桌面和用户数据。

## 6. 已修复的重要问题

1. 删除「未分类」和取消「关闭时结束进程」在更新后复现：用删除策略和持久偏好文件保留选择；升级就绪信息核对分类和关闭偏好。
2. 其他分类的文件/文件夹不可见：曾按完整清单恢复显示；后续不可拿早期索引覆盖当前状态。
3. 更新助手瞬时读取锁误报：新版优先通过硬链接发布已关闭的就绪标记，助手对短暂 IO/读取异常重试；旧 0.11.4 助手到 0.12.0 连续两次升级通过。
4. 任务栏图标仍旧/变成通用图标：图标资源迁到安装目录 `Branding/Qingxia-版本.ico`，开始菜单与固定入口同时同步。不可写时使用 CommonDocuments 中按用户 SID 隔离的公开缓存；检测加密位置换缓存，不解除加密。固定入口目标、参数、工作目录、其他软件入口必须保留。
5. 菜单看起来旧且比例大：全部应用内 ContextMenu 统一品牌标题、蓝青面板与高亮，按面板约束滚动；文字不套整体缩放或阴影位图。

任务栏历史缓存有时需要通过 Windows 原生固定动作重建入口；最后现场已恢复原固定位置。该设备存在第三方桌面/任务栏组件，UI 自动化可能不能枚举其弹窗。不要硬编码屏幕坐标，也不要无记录地重启 Explorer；操作前核对目标并保护已打开的文件夹窗口。
