## 5. 数据保护与恢复边界

默认数据根目录含 `state.json`、`.bak`、`preferences.json`、`.bak`、`category-policy.json`、`migration.json`、`vault/`、`updates/`、`instance.pid` 等。

- 普通文件/文件夹可能托管在原桌面同卷的隐藏 `.DesktopNookVault`。只备份 JSON 或默认数据目录不能覆盖所有真实内容。
- 索引格式 2 允许删除「未分类」，但必须至少有一个分类；不要再自动补回默认分类。
