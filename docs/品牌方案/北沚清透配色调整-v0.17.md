# 北沚清透配色与反射调整 v0.17

沿[光洁玻璃 v0.16](北沚光洁玻璃-v0.16.md)继续调整，遵循用户不使用磨砂的要求。保留饱满身形、大幼芽、卷浪和神态，主要改变配色及反射细节。

使用内置 imagegen 参考图编辑，产物为浅色背景材质预览，尚不是透明图标资源。仍待用户评审，未完成任务栏尺寸、DPI 或 ICO 验收，不替换程序名称、图标或用户数据。旧稿保留供对比。
