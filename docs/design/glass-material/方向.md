# 玻璃材质方向契约

## Direction contract

THESIS: 以连续、真实柔化的背景形成一整块玻璃，保持折页现有双栏操作结构。

OWN-WORLD: 中性浅灰与烟灰底色、少量天蓝操作色、细边缘高光；原色图标和名称直接置于玻璃，移除独立底板。便签采用一片更稳定的阅读底色，记录卡片只作轻量分隔。

STORY: 用户打开软件、切换分类、编辑和勾选便签；操作与存储语义保持。材质更新不触碰真实收纳内容。

FIRST VIEWPORT: 保留顶栏、左侧收纳、右侧便签、统计行格式工具和底栏；背景单独采样与柔化，前景图标、文字与输入控件始终清晰。标志性交互是背景变化时材质随之更新，收起时释放采样与背景缓冲。

FORM: seed: none (pinned)。用户先明确“是加一个玻璃效果的主题，不是一个主题的设置效果”，随后指出“想要那种通透的，且收纳的图标不够清晰”，在查看三组社区材质参考后要求“将这几个的案例的优点综合到我的项目里面来”。这授权改进独立玻璃主题的整体材质和前景辨识度；现有收纳/便签双栏及首屏操作保持产品原结构。本轮采用 Operate/code-led 范围内的主题扩展，不替换产品布局。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## 参考与边界

- [Liquid Glass for GNOME](https://github.com/ryohsuke1231/liquid-glass)：连续材质、前后景分离、稳定阅读面。
- [Seelen (Almost) Liquid Glass Dockbar](https://seelen.io/pt-PT/resources/FRpND2QMTza2e0CKWar_hw/almost-liquid-glass-dockbar)：克制的边缘高光及圆角轮廓。
- [WinMac Dock](https://github.com/Asteski/WinMac-Dock)：Windows 原色图标与原生操作语义。
- 背景采样实现参考 Windows API 文档及公开实现的结构，独立编写 C# 代码，不拷贝第三方素材、着色器或程序。运行时图像仅驻留内存，不保存、不上传，也不修改普通截图/共享屏幕的窗口显示策略。
- 单显示器、小于 8 MiB 原始采样帧启用实时背景；不可用时回退为稳定、不透明的阅读底色。当前功能不承诺未实测的混合 DPI 多屏。
