07 / IMPLEMENTATION

从设计到 WPF 的实施顺序

先令牌和图标，再共享组件与主面板，最后次级窗口和验收。任何视觉调整都不能以重写用户数据为代价。

六个实施阶段

  1. 建立独立沙箱与当前界面基线。
  2. 语义令牌、显示名和兼容资源映射。
  3. 重绘权威图标并生成十种尺寸。
  4. 共享组件、通用弹窗、主面板与便签。
  5. 设置、任务栏外观、更新和游戏外壳。
  6. 隔离验证、源码推送、新版本构建与发行。

不可突破的边界

  • DesktopNook 内部标识、AUMID、数据与资产名保持不变。
  • 真实分类、索引、排序、Notes、Games 和恢复清单不改写。
  • 不移动真实内容做截图，不自行重启 Explorer。
  • 不以晶瓷效果为由增加常驻缓存或额外运行时。
