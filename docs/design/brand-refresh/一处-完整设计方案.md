## 2. 产品理解与设计目标

### 2.1 产品不是单一启动器

“一处”同时承载三类高频行为：

1. **收好**：将桌面快捷方式、文件、文件夹和回收站按用户的分类收纳。
2. **取用**：通过任务栏入口打开面板，单击启动、拖出恢复或使用 Shell 操作。
3. **记下**：在同一面板管理项目便签、文字记录和待办清单。

图标台球、好友联机和任务栏外观属于扩展能力，不能抢占主路径。

### 2.2 目标用户

- 桌面图标较多，但希望自己掌握分类和位置的人。
- 需要快速启动常用项目，同时随手记录待办的人。
- 偏好轻量、本地、可恢复的工具，不希望被复杂控制台打断的人。

### 2.3 设计目标

- **一眼有秩序**：顶栏、分类、内容、状态各有明确层级。
- **一步到常用**：每侧只保留一个主动作，减少同权重按钮。
- **年轻不幼稚**：使用高明度蓝莓蓝和少量蜜桃橙，不使用大面积糖果色。
- **有质感不炫技**：晶瓷质感主要集中在应用图标；工作界面以轻薄表面为主。
- **改名不改数据**：显示层可重构，业务模型和兼容标识不动。

### 2.4 非目标

- 不重做收纳、恢复、排序或 Notes 数据格式。
- 不新增全局搜索、AI 整理、云同步、账号体系或未立项功能。
- 不为了统一视觉而重绘 Windows 自身的任务栏跳转列表。
- 不改变台球规则、联机拓扑、网络监听策略或成绩存储。
- 不以视觉改造为由提高常驻内存或引入额外运行时。

## 3. 品牌命名与文案系统

### 3.1 名称

**一处**

含义：常用应用、文件和灵感，不再分散，都可以集中在一处、从一处取用。

英文辅助名 **YICHU** 仅用于品牌页、关于页或发行说明，不与中文名称重复挤入任务栏标题。

### 3.2 标语

**常用与灵感，都在一处。**

辅助表达：

- 面板副标题：`桌面工作台`
- 便签副标题：`想法，也放在一处`
- 空状态主文案：`把常用，放在一处`
- 空状态说明：`将桌面图标拖到这里，或点击“添加图标”。`

### 3.3 文案语气

- 使用自然、直接的中文，不堆叠“智能、极致、颠覆”等宣传词。
- 按钮保持动作明确：`添加图标`、`记一条`、`查看归档`、`打开设置`。
- 危险操作必须写清对象、结果和可恢复性，不使用“确定要这样做吗？”这类模糊问题。
- 更新提示只描述已核验事实，不夸大为“绝对安全”或“永不丢失”。

### 3.4 显示名与内部名

允许修改：

- 窗口标题、菜单品牌标题、文件说明、开始菜单显示名、安装显示名。
- 对话框、空状态、关于页、更新说明中的用户可见品牌。

必须保持不变：

- `DesktopNook` EXE / 程序集及产品内部标识。
- AUMID：`DesktopNook.DesktopNook`。
- 数据目录、注册表键、卸载兼容键和内部卸载文件名。
- GitHub 资产名：`DesktopNook-win-x64.exe`、`DesktopNook-Setup.exe`。

“轻匣”只保留在迁移说明、历史文档和兼容逻辑中，不应在新主界面继续作为并列品牌出现。

## 4. 应用图标设计

### 4.1 核心概念：三定一取

图标由蓝莓蓝晶瓷底座和四个模块组成：

- 三个冰白模块表示已安放的应用、文件和便签。
- 右下蜜桃橙模块轻微抬起，表示从一处随手取出。
- 蜜桃橙不是未读数量、警告或通知标记，不在其上添加数字。

### 4.2 标准图标几何

以 1024×1024 视窗为基准：

| 元素 | 几何参数 |
| --- | --- |
| 底座 | `x=32, y=32, width=960, height=960, rx=224` |
| 底座底色 | 左上 `#A9C7FF` → 右下 `#7D9CF3` |
| 冰白模块 | 264×264，圆角 66 |
| 模块 1 | `x=218, y=248` |
| 模块 2 | `x=542, y=248` |
| 模块 3 | `x=218, y=574` |
| 蜜桃模块 | `x=542, y=540`，比其他模块上移 34 |
| 冰白模块填色 | `#FFFFFF` → `#E2ECFC` |
| 蜜桃模块填色 | `#FFC4B3` → `#FF927E` |
| 模块描边 | 白色，透明度 46%–58%，约 7 单位 |
| 顶部高光 | 低透明白色，禁止形成刺眼镜面光带 |

标准图标详见 `yichu-mark.svg`。

### 4.3 晶瓷材质规则

必须包含：

- 柔和纵向或斜向渐变。
- 轻微顶部高光和内侧边缘光。
- 模块与底座之间的短接触阴影。
- 蜜桃模块的小幅抬起，而不是强透视或夸张 3D 倾斜。

禁止包含：

- 复杂纹理、噪点、玻璃裂纹、强金属反射。
- 多层外发光、长投影、连续动画高光。
- 将四个模块做成四个独立应用图标或字母。

### 4.4 小尺寸规则

16–24 px 使用 `yichu-mark-small.svg` 的简化思路：

- 取消位移、接触阴影和细高光。
- 保留蓝莓底座、三个冰白格和一个蜜桃格。
- 底座使用略深的 `#86A7F0`，保证浅任务栏中的轮廓。
- 以 `#C5D6F7` 的细轮廓防止与浅背景融合。
- 四格在 16 px 下必须仍保持可分辨的间隙。

### 4.5 尺寸与留白

- 正式 ICO：16 / 20 / 24 / 32 / 40 / 48 / 64 / 96 / 128 / 256 px。
- 界面 PNG：256 px，另按实际 DPI 提取，不放大低分辨率缓存。
- 图标四周最小留白为图标宽度的 12.5%。
- 任务栏和标题栏中不额外添加文字、角标或圆形底板。
- 24 px 以下不附加品牌英文。

### 4.6 WPF 正式资源实施

1. 以 `native/DesktopNook.App/Assets/AppIconDrawing.xaml` 为唯一权威生产矢量源重绘。
2. 使用 `GeometryDrawing`、`LinearGradientBrush` 和必要的简单高光层。
3. 大图标可使用有限 `DropShadowEffect`；16–24 px 分支移除阴影和位移。
4. 通过 `native/scripts/Make-Icon.ps1` 独立渲染十种 ICO 和界面 PNG。
5. 构建脚本不得把浏览器截图、带底色的预览图或外部 SVG 直接塞入正式资源。
6. 公开 ICO 继续放安装目录 `Branding`；不可写时使用按 SID 隔离的 CommonDocuments 缓存，不解除 EFS。

## 5. 色彩系统

### 5.1 使用比例

- 约 75%：白色与极浅蓝灰表面。
- 约 18%：蓝莓蓝选中态、主按钮和重点层级。
- 不超过 7%：蜜桃橙及其他状态色。

蜜桃橙主要用于品牌图标。主界面不大面积铺蜜桃橙，不与蓝莓蓝争夺操作层级。

### 5.2 浅色语义令牌

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `CanvasBrush` | `#F6F9FF` | 主面板底色 |

| `SurfaceBrush` | `#FFFFFF` | 顶栏、卡片、输入框、弹窗 |
| `SurfaceSubtleBrush` | `#F0F5FC` | 状态栏、浅色分组 |
| `TextPrimaryBrush` | `#27334A` | 主文字 |
| `TextSecondaryBrush` | `#647084` | 次级文字、说明 |
| `TextFaintBrush` | `#8A96AA` | 仅限非关键装饰或禁用信息 |
| `LineBrush` | `#DCE5F3` | 分隔线、默认边框 |
| `PrimaryBrush` | `#A9C5FA` | 主按钮、开启状态、进度 |
| `PrimaryHoverBrush` | `#97B8F4` | 主按钮悬停 |
| `PrimaryPressedBrush` | `#84A9EC` | 主按钮按下 |
| `OnPrimaryBrush` | `#1E2E4B` | 浅蓝底上的文字与图标 |
| `AccentInkBrush` | `#3D63B0` | 链接、选中文字、焦点 |

### 5.3 状态色

| 状态 | 前景 | 背景 | 规则 |
| --- | --- | --- | --- |
| 成功 | `#2E7354` | `#E6F6EE` | 同时显示勾选或明确文字 |
| 警告 | `#8A5A12` | `#FFF4D6` | 不只使用黄色表示风险 |
| 错误 / 危险 | `#B84655` | `#FDECEF` | 危险主按钮可白字配 `#B84655` |
| 信息 | `#3D63B0` | `#E2ECFC` | 不与主选中态混淆，附信息图标 |

禁用态：

- 背景 `#EDF0F6`，文字 `#98A2B5`，边框 `#E1E6EF`。
- 禁用控件不能只降低整个窗口透明度，避免影响其他内容。
- 禁用原因需要可发现，可用说明文字或 ToolTip。

### 5.4 深色语义令牌

### 5.5 对比度基线

| 组合 | 对比度 | 结论 |
| --- | ---: | --- |
| 浅色主按钮文字 `#1E2E4B` / `#A9C5FA` | 7.79:1 | AA / AAA 正文 |

## 6. 字体与排版

### 6.1 字体族

```text
Segoe UI Variable, Microsoft YaHei UI, Segoe UI, sans-serif
```

WPF 可保留 `UiFontFamily` 资源键，回退为 `Microsoft YaHei UI, Segoe UI`。

### 6.2 字号层级

以下尺寸均指 WPF 逻辑像素 / DIP，不是物理像素。

| 层级 | 字号 / 建议行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 品牌展示 | 32–48 / 1.15 | 650–700 | 品牌页，不用于主面板标题 |
| 窗口标题 | 17 / 24 | 600 | 独立窗口标题 |
| 面板品牌名 | 16 / 22 | 650 | 主顶栏“一处” |
| 区域标题 | 15 / 22 | 600 | 桌面收纳、便签与待办 |
| 正文 | 13 / 20 | 400 | 对话框正文、设置说明 |
| 图标名称 | 12 / 16 | 400–500 | 图标网格 |
| 按钮文字 | 12 / 18 | 600 | 主要与次要操作 |
| 辅助信息 | 11 / 16 | 400 | 分类数量、状态说明 |
| 元数据 | 10 / 14 | 400 | 时间戳等非关键内容 |

### 6.3 排版规则

- 不再以 9 px 呈现可读操作或关键说明。
- 图标名称默认单行省略，完整名称通过 ToolTip 和 Shell 操作获得。
- 便签标题最多两行；正文保持用户原始换行和 Markdown 语义。
- 数字统计尽量与文字基线对齐，不单独使用过小字号。
- 中文正文不使用整体字符拉伸、位图缩放或文字阴影。
- `TextFormattingMode=Display`、`UseLayoutRounding=True`，保留原生 DPI 排版。
- 输入法组字期间不得重排卡片、重建输入框或抢回焦点。

## 7. 间距、圆角、边框与阴影

### 7.1 基础间距

使用 4 px 基础网格：

`4 / 8 / 12 / 16 / 20 / 24 / 28 / 32`

允许 6 px 用于紧凑的内部文字间距，不允许出现无规律的 7、13、17 px 连续混用。

### 7.2 圆角

| 元素 | 圆角 |
| --- | ---: |
| 小标签、勾选框 | 4–6 |
| 普通按钮、输入框 | 8 |
| 图标 tile、便签卡片 | 10 |
| 菜单、中小型弹窗 | 12–14 |
| 主面板 | 18 |
| 品牌图标底座 | 约 22% 边长 |

### 7.3 边框

- 默认 1 DIP `LineBrush`。
- 选中 tile 可使用 1 DIP `AccentInkBrush`，同时加勾选标记。
- 键盘焦点使用 2 DIP 外轮廓，不能只改背景色。
- 分隔线比卡片边框更弱，不能形成多层套娃边框。

### 7.4 阴影

| 层级 | 建议值 |
| --- | --- |
| 主面板 | `0 20 60 rgba(50,75,130,.16)` |
| 独立弹窗 | `0 16 44 rgba(50,75,130,.14)` |
| 卡片 | 默认无阴影；悬停可用 `0 6 18 rgba(50,75,130,.07)` |
| 应用图标模块 | 短接触阴影，参考 SVG，不用于普通按钮 |

WPF 中优先使用边框和背景区分层级，避免在大量 tile 上同时启用实时模糊阴影。

## 8. 主面板详细布局

### 8.1 默认尺寸与结构

- 默认逻辑尺寸：**1080×620 DIP**。
- 最小建议尺寸：**860×520 DIP**，低于此尺寸优先减少列数和隐藏副标题。
- 最大尺寸：所属屏幕工作区的 92%，继续复用现有窗口边界逻辑。
- 顶栏：56 DIP。
- 主体：564 DIP。
- 左栏：61%；右栏：39%；中间分隔线：1 DIP。
- 保留现有左右 61:39 的用户调整能力，不新增第二套比例记录。

> 当前生产逻辑面为 1000×560。改变默认尺寸必须同步检查 `WindowSizing.cs`、添加窗口 88% 约束、屏幕定位、动画截图和多 DPI 验收，不能只改 XAML 的 Width/Height。

### 8.2 顶栏：56 DIP

左侧：

- 应用图标 30×30。
- 名称“一处”，16 DIP / SemiBold。
- 副标题“桌面工作台”，11 DIP；宽度不足时首先隐藏。
- 项目数量可作为轻量文本，不再叠加多个胶囊。

右侧：

- `图标台球`：文字＋线性图标，作为低频入口。
- `设置`：32×32 图标按钮。
- 窗口分隔符。
- `最小化`、`关闭`：各 32×32 图标按钮。

顶栏不再同时摆放添加、设置、更新、更多等所有动作。

### 8.3 左侧：桌面收纳

区域标题栏 60 DIP：

- 标题：`桌面收纳`，15 DIP。
- 辅助：`24 个项目 · 单击启动`，11 DIP。
- 主动作：`＋ 添加图标`，34 DIP 高，浅蓝底深字。

分类栏 42 DIP：

- 分类标签高 30–32 DIP，水平内边距 10。
- 当前分类：`SelectionBrush` 背景、`AccentInkBrush` 文字，并附 2 DIP 下划线。
- 分类过多时横向滚动，保持拖动手势与自动边缘滚动。
- `新建分类` 放在栏末，使用图标按钮。

内容区：

- 默认 1080 宽度下使用 **5 列**，列数由 `WindowSizing.cs` 根据实际左栏宽度计算，不写死。
- 图标 tile 建议高 88 DIP，图标图像 36×36，名称 12 DIP。
- tile 间距 8 DIP，内容左右内边距 20，顶部内边距 16。

## 14. 组件规范

### 14.1 按钮

| 类型 | 默认 | 悬停 | 按下 | 焦点 |
| --- | --- | --- | --- | --- |
| 主按钮 | `#A9C5FA` / `#1E2E4B` | `#97B8F4` | `#84A9EC` | 2 DIP `AccentInkBrush` 外框 |
| 次按钮 | 白底＋`LineBrush` | `SelectionHoverBrush` | `SelectionBrush` | 同上 |
| 幽灵按钮 | 透明 | `SelectionHoverBrush` | `SelectionBrush` | 同上 |
| 危险按钮 | `#B84655` / 白字 | `#A53D4B` | `#913440` | 2 DIP 深色外框 |

尺寸：

- 普通按钮最小高 34，水平内边距 12–14。
- 图标按钮视觉尺寸 32×32，建议实际命中区 36–40。
- 主按钮文本 12 / SemiBold，不全部使用大写或全角空格撑宽。

加载状态：

- 保留原按钮宽度。
- 文案改为当前动作，例如 `下载中…`，并禁止重复提交。
- 不仅依赖 spinner 表示状态。

### 14.2 分类标签与分段控件

- 默认透明，文字 `TextSecondaryBrush`。
- 悬停 `SelectionHoverBrush`。
- 选中 `SelectionBrush`＋`AccentInkBrush`，并加下划线或勾选。
- 焦点外框与选中样式可以叠加。
- 拖动中的标签保持原位置占位，不让布局突然跳动。

### 14.3 输入框

- 高 34，圆角 8，白底，1 DIP 边框。
- 聚焦：边框 `AccentInkBrush`，外圈 2 DIP 半透明蓝莓蓝。
- 错误：边框 `DangerBrush`，错误说明位于下方，不只改变文字颜色。
- 只读：使用 `SurfaceSubtleBrush`，仍允许复制文本。
- 输入法和复制粘贴不得触发额外格式化，除非已有明确业务行为。

### 14.4 勾选框、开关、单选

- 勾选框 16×16，命中区不小于 32×32。
- 开启开关宽 36、高 20，滑块 16；关闭使用中性灰。
- 选中状态同时使用形状、勾选和文字，不能只换颜色。
- 禁用状态保留标签可读性。

### 14.5 下拉框、滑块和滚动条

- 下拉框高 34，弹出菜单最大高 240，可滚动。
- 滑块轨道 4 DIP，滑块 16 DIP，当前值以文字显示。
- 滚动条宽 7，滑块圆角 3；悬停时增强，不持续抢视觉。
- 滚动区域不裁剪焦点轮廓。

### 14.6 菜单与 ToolTip

- 应用内菜单圆角 12，菜单项高 32–34，危险项单独分组。
- 品牌头部高 32，显示 17 px 图标和“一处”。
- ToolTip 使用深青灰底白字、12 DIP、圆角 7，延迟与系统习惯一致。
- Windows 自身任务栏跳转列表继续系统绘制，只同步名称、图标和 AUMID。

### 14.7 进度、Toast 和行内反馈

- 保存成功优先使用状态栏行内反馈。
- 更新下载使用确定进度；未知进度才使用不定进度。
- Toast 只用于不需要立即处理的短反馈，不能替代错误详情。
- 行内错误与对应字段相邻，网络异常与对应操作相邻。

## 16. 动效规范

### 16.1 基本原则

- 动效解释状态变化，不成为装饰。
- 保留现有两组共十种开合效果、偏好和截图缓冲复用。
- 新视觉只替换颜色、表面与组件过渡，不重写主窗口状态机。

### 16.2 建议时长

| 场景 | 时长 |
| --- | ---: |
| 按钮悬停 | 100–120 ms |
| 按下 | 70–90 ms |
| 分类 / 视图切换 | 140–180 ms |
| 菜单 | 140–180 ms |
| 普通弹窗 | 220 ms，透明度＋10 DIP |
| 主面板 | 沿用当前效果；轻量默认可从 320 ms / 18 DIP 起评 |

### 16.3 禁止事项

- 不让动画完成回调直接改写业务状态或分类顺序。
- 拖动排序时不播放布局追赶动画。
- 不为晶瓷图标添加无限循环高光。
- 不在每个 tile 上保留独立动画时钟。
- 动画关闭或跟随系统减少动效时立即提交最终状态。
- 不增加强制 GC、工作集裁剪或永久截图缓存。

## 17. 响应式、DPI 与可访问性

### 17.1 宽度适配

- 左栏不足时依次：减少列数 → 隐藏副标题 → 缩短辅助统计。
- 右栏不足时优先合并次要操作到更多菜单，不把正文压到 10 px 以下。
- 低于最小建议宽度时使用既有最小尺寸与滚动，不允许控件重叠。
- 分类与便签拖动分隔线继续实时布局，Esc 恢复原比例。

### 17.2 DPI 与多屏

至少检查 100% / 125% / 150% / 175% / 200%：

- 文字没有裁切、重影和模糊位图缩放。
- 图标按实际 DPI 提取。
- 菜单不超出工作区，焦点轮廓完整。
- 任务栏定位、添加窗口 88% 上限和游戏窗口边界正确。
- 混合 DPI 多屏结果如实记录，未实测不得宣称通过。

### 17.3 键盘与屏幕阅读器

- Tab 顺序按视觉阅读顺序：顶栏 → 左栏 → 右栏。
- 所有图标按钮有 `AutomationProperties.Name`。
- 图标网格支持方向键、Enter 启动、Space 选择和上下文菜单键。
- Esc 优先取消当前弹窗、拖动或预览。
- 焦点始终可见，弹窗关闭后返回触发按钮。
- 状态变化不仅靠颜色，保存、错误和选中都有文字或图形反馈。

### 17.4 高对比与减少动效

- 系统高对比模式下不强行覆盖系统文字色。
- 自定义焦点、边框和状态不能依赖阴影才能辨认。
- 尊重 `MotionMode=system/on/off` 和 Windows 客户区动画设置。

## 23. 最终设计摘要

“一处”的核心不是把所有界面做成蓝莓色，而是建立一个清楚的秩序：

- **一个名字**：常用与灵感，都在一处。
- **一个图标**：三定一取，蓝莓蜜桃晶瓷四格。
- **一个主动作**：每侧只突出当前最高频操作。
- **一套语义色**：浅蓝负责操作，深蓝负责阅读，蜜桃负责点睛。
- **一套实施边界**：显示层可以焕新，用户数据和兼容逻辑绝不让步。
