# 界面与交互规范

当前产品名为轻匣，使用蓝青 A2 折角图标。权威资源为 `native/DesktopNook.App/Assets/AppIconDrawing.xaml`，生成 PNG 和十种 ICO，不用旧候选稿或带白底预览图替代程序资源。

## 视觉

- 蓝/青主色、浅色面板、深蓝文字、蓝色渐变主按钮，折面保留适度光感。
- 主面板、分类、输入、勾选项、收纳、编辑及更新窗口共享圆角、边框、焦点和禁用状态。
- 应用内图标右键、分类、更多和子菜单共享品牌标题区、蓝青面板、高亮与分隔线；尺寸受面板约束，可滚动。
- 文字按原生 DPI 排版，阴影与文字分层；不整体缩放菜单文字位图。
- 任务栏系统菜单保留 Windows 外观，只同步应用名称、图标和标识。

## 交互

单击打开，任务栏同一入口打开/收起。支持直接拖入、拖回、排序和拖到分类；Esc 优先取消当前操作。分类删除说明内容流向，最后一个分类受保护。同名恢复不覆盖，失败保留原内容与恢复依据。

基础操作和设置语义统一，未来效率工具的核心流程按用途设计，未立项功能不作为已实现能力展示。视觉调整不能变更分类 ID、索引、存储位置和取消勾选的偏好。

## 系统入口

公开版本 ICO 优先放在安装目录 Branding；不可写时使用 CommonDocuments 下按 SID 隔离的公开缓存。遇到加密位置换缓存，不解除任何文件或目录加密。开始菜单与固定入口一起同步，只处理目标等于本程序的快捷方式。
