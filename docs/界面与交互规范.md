# 界面与交互规范

当前产品为折页 / ZHEYE。图标由两片不等宽纸页、中央折痕与右上折角组成。生产矢量由 AppIconDrawing.xaml 和小尺寸变体生成十种 ICO 及界面 PNG。系统入口使用默认葡萄气泡图标。

0.21.0 的经典纸页、柔雾纸页、通透玻璃与悬浮任务栏设置见[悬浮任务栏与界面风格](悬浮任务栏与界面风格.md)。材质选择与配色、明暗模式独立；高对比度或窗口合成不支持时使用不透明表面。

## 视觉

- 0.21.22 的「晴空玻璃」是主题列表中的独立主题，包含语义配色、图标及自动通透材质，支持明暗模式；无需选择额外风格开关。`VisualStyle` 保留其他主题的原偏好，高对比度使用不透明表面。
- 颜色统一为带可见名称的色块网格。便签加粗、删除线和背景标注色移到分类统计行，使用当前选中的正文/待办文字；无有效选区或归档只读时禁用。统计按记录、待办总计、待完成、已完成排列；窄窗口允许统计文字换行，保留工具和完整信息。
- 场景直接点选，未启用单独设置时显示桌面继承值且禁止编辑。开启时从桌面开始，已有独立设置关闭再启用可恢复；模式和场景调整只改草稿，点击应用保存，切换场景/模式结束旧预览。

- 0.21.20 增加晶透玻璃：保留背景的真实透明度、细描边及高光，便签卡片保留较高不透明度以保证阅读。它与配色、明暗模式独立；高对比度模式使用不透明表面。
- 顶栏图钉开启后失焦不收起，主动最小化与任务栏开合仍有效。便签标题旁 B 为所选正文/待办文字加粗，支持键盘 Ctrl+B 和右键操作。
- 0.21.21 的图钉常驻显示「已钉住 / 未钉住」文字，选中使用主题实色背景和实心图钉。其模板自己处理悬停、按下和焦点，禁用通用 UiMotion.Feedback 对背景的接管，避免悬停覆盖选中效果。点击成功后在底部确认，保存失败时维持原状态并显示错误。
- 任务栏设置默认显示常用外观项，高级区域保留场景、信息球及模糊半径。标准色共 30 色，便签背景标注共 12 色。

- 支持葡萄气泡、西瓜冰棍、青柠电波、蓝莓苏打与晴空玻璃五套主题，明暗模式独立。主色用于主要操作与选中态，珊瑚色用于便签入口，薄荷绿用于已完成待办。纸页主题左为方格纸、右为横线纸，新数据默认分栏比例为 61:39。
- 主面板、分类、输入、勾选项、收纳、编辑及更新窗口共享圆角、边框、焦点和禁用状态。
- 应用内图标右键、分类、更多和子菜单共享品牌标题区、主题表面、高亮与分隔线；尺寸受面板约束，可滚动。
- 文字按原生 DPI 排版，阴影与文字分层；不整体缩放菜单文字位图。
- 任务栏系统菜单保留 Windows 外观，只同步应用名称、图标和标识。

## 交互

单击打开，任务栏同一入口打开/收起。支持直接拖入、拖回、排序和拖到分类；Esc 优先取消当前操作。分类删除说明内容流向，最后一个分类受保护。同名恢复不覆盖，失败保留原内容与恢复依据。

基础操作和设置语义统一，未来效率工具的核心流程按用途设计，未立项功能不作为已实现能力展示。视觉调整不能变更分类 ID、索引、存储位置和取消勾选的偏好。

## 系统入口

公开版本 ICO 优先放在安装目录 Branding；不可写时使用 CommonDocuments 下按 SID 隔离的公开缓存。遇到加密位置换缓存，不解除任何文件或目录加密。开始菜单与固定入口一起同步，只处理目标等于本程序的快捷方式。
