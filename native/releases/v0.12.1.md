# 轻匣 0.12.1

修复更新后任务栏固定入口仍显示旧图标的问题，并重新设计应用内全部右键与更多菜单。

- 固定入口引用独立版本 ICO，并刷新 Windows 图标关联；保留快捷方式目标、参数、原文件名和固定顺序，不影响其他软件。
- EXE 原位更新后自动同步开始菜单与已登记安装显示名、图标和版本，沿用原来的程序与数据位置。
- 图标右键、分类右键、更多菜单及子菜单统一蓝青标题区、圆角渐变面板、高亮和分隔线；保留系统 Shell 操作与随面板尺寸调整的滚动能力。
- 菜单文字继续按原生弹出窗口 DPI 排版，不整体缩放文字。

37 项隔离原生检查通过，包括菜单边界、子菜单清晰度、固定入口图标迁移、参数保留与其他快捷方式保护。图标关联修复前后真实分类与偏好哈希保持一致。Windows 原生任务栏右键菜单由系统绘制，此次同步其应用标识和图标，不替换系统菜单外观。
