# 轻匣 0.13.1 · 台球球组与紧凑窗口

- 数量滑块改为四种固定球组：中八 15 球、斯诺克 21 球、九球追分 9 球、十五球追分 15 球，各另有一颗白球。按所选规则切换配色和开局摆法；保持单人清台练习。
- 图标以圆球显示，使用全色 / 花色或斯诺克红彩球配色，原图标保留在球面的圆形小标中，编号也限制在圆球轮廓内。
- 游戏默认宽、高各为所在屏幕的一半，总面积约四分之一，初始居中；窄窗口操作栏自动分行。
- 移除游戏右下角许可按钮及底部尺寸 / 缩放提示。完整 MIT 许可仍随程序嵌入，可从「更多 → 桌面玩法 → 开源许可」查看。
- 记录所选球组，最佳成绩按球组分别保存；兼容已有来源、辅助线设置和旧成绩，旧自由数量默认转为中八。

主收纳数据及分类顺序格式不变。按需游戏进程、退出清理、共享 .NET 10 Windows Desktop Runtime x64 依赖和单 EXE 分发保持。
