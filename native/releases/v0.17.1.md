# 轻匣 0.17.1

补齐「更多 → 任务栏外观」的设置。桌面与各动态场景可以分别配置。

- 支持系统默认、透明、纯色、模糊和亚克力。可选颜色、调不透明度及模糊半径。
- 支持可见窗口、最大化、开始菜单、搜索、任务视图和节能模式六种动态场景。选择场景后可单独启用和预览。
- 可调整任务栏顶部细线，保留旧式任务栏的 Aero Peek 设置。可见窗口和最大化场景支持窗口规则，并可设置忽略列表。
- 导入 TranslucentTB 配置时，场景、窗口规则和忽略列表会一并导入。0.17.0 已保存的外观设置继续适用。

本版沿用 0.17.0 的渲染组件与 26340 兼容组件。模糊半径和 Aero Peek 等选项取决于 Windows 的任务栏类型。验证覆盖界面、配置导入和组件配置传递。
