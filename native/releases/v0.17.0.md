# 轻匣 0.17.0

在「更多 → 任务栏外观」可以选择系统默认、透明或纯色，调整颜色和不透明度。应用前可预览 12 秒，取消或超时会回到上次保存的外观。

- 首次启用时，轻匣会提示下载并校验所需组件。Windows 26340 使用随发行版提供的兼容组件，支持手动导入 ZIP。
- 可以导入 TranslucentTB 独立版的桌面样式配置。若独立版仍在运行，轻匣会提示先退出独立版。
- 当前发行包还附带兼容组件对应源码及许可证。下载完成后可用 `SHA256SUMS.txt` 核对。

如果正在试用 0.17.0 预览版，请从发行页手动下载安装正式版。预览版和 0.17.0 正式版的数字版本相同，旧预览程序可能不会弹出更新提示。
