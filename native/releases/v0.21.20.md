# 折页 0.21.20

- 新增「晶透玻璃」界面风格，采用真实半透明表面、边缘高光和半透明便签卡片，支持浅色、深色及四套配色。在高对比度模式下回退为不透明表面。
- 顶栏新增图钉，可保持面板展开，点击其他窗口时不再自动收起。状态自动保存，主动最小化和任务栏开合仍然有效。
- 修复胶囊任务栏中同一软件多个窗口点击无响应：系统未能弹出预览时显示可点击的实时窗口缩略图，选中后还原并激活对应窗口。
- 简化任务栏外观设置，将常用形态、样式、颜色放在前面，场景规则和信息球连接放入默认折叠的高级设置，保留预览、应用及恢复操作。
- 任务栏选色增加 30 个标准色，便签文字背景色扩充为 12 色。
- 便签正文和待办内容支持选中文字加粗，可用 B 按钮、右键菜单或 Ctrl+B。保存、重新打开、文字与清单互转及 Markdown 导出均保留格式。

多窗口恢复已在现有 Windows 任务栏上使用三个隔离窗口和真实鼠标验证；不涉及重启 Explorer 或移动用户文件。其他 Windows 版本、跨显示器及混合 DPI 仍需额外实机覆盖。
