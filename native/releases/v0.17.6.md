# 轻匣 0.17.6

- 任务栏引擎在轻匣进程内运行。启用外观时，任务管理器中无需启动独立的 TranslucentTB。
- 保留任务栏外观与场景设置。升级后首次启用，请打开「更多 → 任务栏外观」并同意下载新的 x64 组件，大小约 0.8 MB。
- 实机验证了 Windows 11 26H2 构建 26340.10013 单屏的纯色、透明、取消预览、恢复系统外观与再次启用。

安装包为 `DesktopNook-Setup.exe`，免安装版为 `DesktopNook-win-x64.exe`。两者使用 .NET 10 Windows Desktop Runtime x64。

本版按 GNU GPLv3 发布。下载 `DesktopNook-v0.17.6-source.zip` 获取与安装包对应的轻匣源码、修改后的任务栏引擎、源依赖、构建脚本与许可证。`Qingxia-TaskbarCore-win-x64.zip` 是应用按需下载的外观组件，包含第三方许可。使用 `SHA256SUMS.txt` 校验发行文件。
