# 轻匣 0.16.0 · 项目便签

- 软件收纳右侧新增项目便签，左右同时显示，共用窗口、任务栏入口与展开收起动画。
- 按项目记录文字和待办，支持项目内搜索、自动保存、常用、跨项目移动与导出。
- 支持项目归档、回收站及恢复；已归档记录只读，恢复后继续编辑。
- 便签独立保存，写入失败保留草稿并提供重试、导出；更新备份包含项目与正文。
- 默认窗口扩宽，分隔线可调整；窄窗减少图标列数，保持正常字号。

升级保留原分类、软件收纳内容、排序和设置，沿用任务栏标识。无需卸载旧版。依赖 .NET 10 Windows Desktop Runtime x64，缺少时安装包可经确认补装。

已通过核心、便签界面、尺寸与原有界面/动画检查。真实中文输入法连续组字、混合 DPI 多屏、大数据及长时间常驻性能仍需更多实机覆盖。
