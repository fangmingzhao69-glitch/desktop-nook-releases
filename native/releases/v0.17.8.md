# 轻匣 0.17.8

- 在待办输入框粘贴多行文字，轻匣会按行拆分成多条待办，跳过空行并去掉 `1、`、`2.` 等列表编号。
- 批量新增的事项放在清单上方。粘贴到空白待办时会直接替换该空行，已有内容的事项继续保留。
- 保留 `~~文字~~` 的局部删除线，识别 Markdown 清单的 `[x]` 和 `[ ]` 状态。单行文字仍按原方式粘贴。

安装包为 `DesktopNook-Setup.exe`，免安装版为 `DesktopNook-win-x64.exe`。两者使用 .NET 10 Windows Desktop Runtime x64。按 GPLv3 提供与安装包对应的源码 `DesktopNook-v0.17.8-source.zip`。
