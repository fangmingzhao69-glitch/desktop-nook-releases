# 一处 0.19.0

- 轻匣的应用显示名更新为「一处」，启用蓝莓蜜桃配色和晶瓷四格图标。常用与灵感，都在一处。
- 主面板采用统一顶栏和桌面收纳、便签与待办双栏。添加图标、菜单、任务栏外观、更新和台球窗口采用同一套视觉样式。
- 顶栏新增独立设置入口。可在「外观」切换浅色、深色或跟随系统，也可调整尺寸、开合样式和动画设置。
- 旧版可直接更新，沿用原有收纳、便签、排序和偏好数据。升级时只迁移指向当前程序的开始菜单快捷方式。

安装包为 `DesktopNook-Setup.exe`，免安装版为 `DesktopNook-win-x64.exe`。两者使用 .NET 10 Windows Desktop Runtime x64。按 GPLv3 提供与安装包对应的源码 `DesktopNook-v0.19.0-source.zip`。
