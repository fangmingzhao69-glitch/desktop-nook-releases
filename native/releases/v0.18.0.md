# 轻匣 0.18.0

- 待办首行的编辑区与勾选框上缘对齐，长内容换行时勾选框留在第一行旁。
- 「更多 → 动画效果 → 开合样式」新增两份演示中的十种效果。上一版的方案有双门对开、图标列队、波浪逐行、三段接力和垂幕落定。第二版的方案有胶囊生长、滑轨推入、对向错层、放射绽放和窗孔开合。
- 新样式开合时间约 345–440 毫秒，支持中途反向切换。原百叶翻转仍可使用，开合样式会随偏好保存。

安装包为 `DesktopNook-Setup.exe`，免安装版为 `DesktopNook-win-x64.exe`。两者使用 .NET 10 Windows Desktop Runtime x64。按 GPLv3 提供与安装包对应的源码 `DesktopNook-v0.18.0-source.zip`。
