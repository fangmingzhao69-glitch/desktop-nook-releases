# 轻匣 0.17.7

- 勾选完成的待办自动移到清单底部，未完成项保持在上方。待办全部勾选后，整份清单移到分类底部。各组内保留原顺序。
- 「添加」移到待办清单的标题同行。点击添加或在待办中按 Enter，新项目出现在第一行并获得输入焦点。
- 选中待办的部分文字后，可在右键菜单添加或取消删除线。部分标记独立保存，勾选整项仍显示整行删除线。Markdown 导出保留部分删除线。

安装包为 `DesktopNook-Setup.exe`，免安装版为 `DesktopNook-win-x64.exe`。两者使用 .NET 10 Windows Desktop Runtime x64。按 GPLv3 提供与安装包对应的源码 `DesktopNook-v0.17.7-source.zip`。
