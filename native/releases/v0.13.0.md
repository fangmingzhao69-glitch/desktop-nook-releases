# 轻匣 0.13.0 · 图标台球

- 新增「更多 → 桌面玩法 → 图标台球」，可选当前分类、全部收纳图标或桌面图标镜像，支持 15～45 个图标。图标不足时只在游戏画面里复制补球。
- 鼠标瞄准、按住左键蓄力、松开击球；支持碰撞、碰库、六个球袋、白球复位、辅助线、计时和清台成绩。可暂停、继续、重开，Esc 退出，失焦或最小化自动暂停。
- 游戏使用 C# / WPF 和按需临时进程，无 Python 依赖。静止时停止帧循环，退出结束游戏进程；日常未打开游戏时不预加载游戏图片。
- 本地偏好、最近 100 局和历史个人最佳保存到当前 Data/Games/IconBilliards。游戏不移动桌面文件、不修改收纳分类或顺序。独立台球窗口采用深青桌布；透明桌面图层另行评估。
- 更新、存储维护或退出主软件前先关闭对局，主进程异常退出也会结束游戏。增加第三方许可入口，保留 Desktop Icon Billiards 的 MIT 版权及许可。

依赖 .NET 10 Windows Desktop Runtime x64，安装包沿用缺失检测及确认后自动补装；保持单 EXE 分发。分类、收纳文件、偏好和独立排序格式不变。测试条件和性能实测见仓库 docs/图标台球实现与验收.md。
