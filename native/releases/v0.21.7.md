# 折页 0.21.7

- 胶囊改用 Windows 合成层绘制平滑圆角，保留对称的边缘留白。应用区和托盘靠拢，中间用细线分隔。
- 打开和关闭应用时，胶囊随图标数量居中伸缩。任务栏暂时把应用放入溢出菜单时，布局保留已经确认的显示空间，避免宽度反复变化。
- 「显示隐藏的图标」面板跟随胶囊的托盘箭头。应用的原生预览和提示按关联图标定位。
- 折页桌面面板的两页底栏使用同一个圆角裁剪，修复左下角出现第二条弧线的问题。
- 对允许普通权限移动的腾讯电脑管家信息球，胶囊提供托盘左侧对齐。Windows 拒绝移动时，胶囊按实际可放入的控件计算宽度。

如果更新时 Windows 资源管理器仍载有旧版组件，可从任务管理器重启一次 Windows 资源管理器。
