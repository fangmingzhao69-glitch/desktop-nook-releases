# 折页 0.21.23

- 晴空玻璃主题提高通透程度，减轻面板底色、顶栏和大面积高光的遮挡；图标和文字保持完整不透明度。
- 收纳图标改为 48 逻辑像素，按实际 DPI 请求更高分辨率的原始图标资源，并在玻璃主题下提供独立图标底衬和名称底衬，减少背景干扰。继续保持可见区域按需加载和 8 MiB 缓存预算。
- 修复胶囊模式下软件图标的系统右键菜单错位：识别 Windows 原生跳转菜单，将菜单定位到所点图标上方，保留系统菜单内容、尺寸和键盘操作。处理仅由真实任务栏右键触发，取消或退出胶囊后结束。

本轮通过 30 项功能检查、8 项原生右键专项、12 项拖动排序；图标专项包含 6 个来源、41 条提取/缩放/缓存结果，其中 3 个来源为只读的已收纳软件快捷方式。当前 Windows 11 单屏验证通过，其他 Windows 版本和混合 DPI 多屏仍需额外实机覆盖。
