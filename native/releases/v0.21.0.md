# 折页 0.21.0

新增可切换的悬浮玻璃任务栏，以及与配色、明暗模式独立的界面风格。升级默认保持现有系统任务栏和经典纸页。

- 外观页新增经典纸页、柔雾纸页、通透玻璃。
- 任务栏页可切换 Windows 系统任务栏和折页悬浮任务栏。悬浮模式提供液态玻璃、柔雾玻璃、纯色，支持悬停放大、窗口预览、固定排序、开始菜单、托盘、状态、日历及多显示器设置。
- 模式切换先试用 12 秒，确认后保存；超时和撤销恢复原模式。悬浮任务栏右键可直接切回系统模式。
- 可从折页收纳图标的右键菜单固定到悬浮任务栏，固定顺序与收纳分类分开保存。
- 新增主进程退出监视与有时限的原生退出处理。隐藏系统任务栏默认关闭；远程控制兼容模式可改为映出壁纸。
- 新配置及原生固定列表纳入更新元数据备份。现有收纳、便签、待办、配色和关闭偏好保留。

悬浮核心基于 Atrium Desktop 的 MIT 开源代码适配，许可证可在关于页查看，源码随发行包提供。组件嵌入主 EXE，启用时按摘要校验解压，继续依赖共享 .NET 10 桌面运行时。

沙箱验证覆盖三种材质真实绘制、12 秒回退、反复启停和主进程异常退出。沙箱保留真实 Windows 任务栏，不代表已经实测系统任务栏隐藏、多屏混合 DPI、HDR 与显卡切换的全部组合。聊天内容监听、独立桌面小组件和台前调度未启用。
