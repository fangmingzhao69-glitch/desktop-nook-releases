新增在线更新：

- 启动后后台检查新版本，也可从“更多 → 检查在线更新”手动检查。
- 发现新版后显示更新说明，确认后下载，支持查看进度与取消。
- 校验下载文件大小、SHA-256、产品名称和版本后，在原位置更新并自动重启。
- 更新保留分类、收纳内容和设置，旧程序副本及更新记录保留在本机。
- 保留“从本地文件更新”入口，网络不可用时仍可手动更新。

从 0.7.x 或更早版本升级：本次请覆盖安装一次；后续可在软件中完成在线更新。

Windows x64，程序内含运行时。安装版下载 `DesktopNook-Setup.exe`，免安装版下载 `DesktopNook-win-x64.exe`。
