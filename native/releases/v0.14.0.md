# 轻匣 0.14.0 · 球盘、音效与双人台球

- 新增下球球盘，按进球顺序显示圆形图标球；双人局按击球方分成两排，白球不计入。彩球或犯规球复位后会从球盘移除，重开清空。
- 每局先显示规则，点击「开始练习 / 开始对战」后进入游戏；可随时用「规则」重新查看。阅读时暂停，计时不会提前开始。
- 新增击球、球碰撞、碰库和入袋音效。球杆击球声在真正出杆时播放，力度越大声音越强、尾音越长；工具栏及开局设置均可关闭并记住选择。
- 新增同机双人模式：显示双方分数、当前击球方、目标及胜负。中八分组及黑球胜负、九球合法进 9 获胜、十五球按球号追至 61 分、斯诺克红彩交替与清彩计分，均提供对应换人、犯规和复位处理。采用开局说明中列出的简化本地规则。
- 初始窗口改为屏幕约 40% 面积并居中，宽高各约为屏幕的 63.25%。

单人历史最佳与双人成绩分开，旧设置和旧成绩保留。仍为按需游戏进程，声音在游戏进程内生成和播放，无额外音频资源下载；退出或暂停会停止当前声音。
