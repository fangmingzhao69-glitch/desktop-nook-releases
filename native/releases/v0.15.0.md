# 轻匣 0.15.0 · 好友邀请联机

- 新增「创建好友房间」「加入好友房间」。复制邀请给朋友，或搜索同网房间；局域网无密钥加入由房主确认。无需账号或自建公网匹配服务器。
- 支持 IPv4 / IPv6 直连和证书指纹校验的 TLS，邀请临时有效，不广播加入密钥。双方阅读规则并准备后开始。
- 房主统一计算物理、回合、犯规及胜负，两端接收同一份球位、分数和球盘；各自软件图案保持本地，文件路径和内容不上传。
- 支持原座位 60 秒自动重连，拒绝越权、重复及过期击球；整局暂停和重开需要双方同意。联机失焦 / 最小化只影响本机操作与绘制。
- 联机成绩独立标记，不覆盖单人最佳；原有本地玩法、左右球盘、实录音效和 40% 居中窗口保留。

本轮按用户选择完成本机双端、IPv4 / IPv6 回环、发现及重连验收。真实两台电脑、跨公网 IPv6 与防火墙组合仍待验收；软件不自动修改 Windows 防火墙或路由器，实际连接依赖双方网络允许入站。
